# Carte de lecteur numérique

Page web installable (PWA), hors connexion, qui affiche une carte de lecteur avec un code-barres
Code 128 généré dans le navigateur (aucune bibliothèque, norme implémentée à la main).

- Les données (nom, numéro) restent **sur l'appareil** (localStorage). Rien n'est envoyé nulle part.
- Les valeurs par défaut sont fictives.
- Projet d'apprentissage : fait avec l'aide d'une IA (Claude), le décodage et la vérification du
  Code 128 ont été testés sur une vraie carte.
